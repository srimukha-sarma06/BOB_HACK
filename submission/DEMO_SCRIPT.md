# FirstPR Academy Demo Script

## 30-second pitch

New contributors waste hours understanding unfamiliar repos before making a safe first pull request.  
FirstPR Academy uses static analysis, vector search, and IBM Bob missions to turn an unknown repo into a tested first contribution path.

## Demo flow

1. Open frontend.
2. Click **Use sample repo**.
3. Show onboarding score and time saved.
4. Show Repo Map:
   - entrypoints
   - tests
   - docs
   - good first files
   - risky files
5. Open Vector Search.
6. Search: `where should I add email validation?`
7. Show retrieved chunks from `src/routes/users.py` and `tests/test_users.py`.
8. Open Bob Missions.
9. Copy **Spell 1** into IBM Bob.
10. Copy **Spell 2** into IBM Bob.
11. Copy **Spell 3** into IBM Bob.
12. Paste Bob outputs into Artifact Vault.
13. Show Submit checklist.

## Final line

FirstPR Academy turns “I don’t know where to start” into a safe, explainable, tested pull request.
