# Bob Prompts

The app dynamically generates these prompts from each analyzed repo.

## Prompt 1: Understand

Ask Bob to explain the repository to a beginner using full repo context.

## Prompt 2: Task selection

Ask Bob to choose three safe first-PR missions and recommend the best one.

## Prompt 3: Implementation

Ask Bob to implement the selected mission, add tests, run tests, and generate a PR summary.

## Prompt 4: Review

Ask Bob to review the final diff and produce interview-ready explanation notes.
